# Compact focused quotation rows

Focused mode puts code/search and a single-line description side by side, with DN/date and relevant Workflow cost attribution on one compact metadata line. Ordinary imported rows no longer show unrelated Cost pending placeholders. Complete descriptions remain in Item details; cost summaries expand to full supplier, tax, time and warning information. Normal-mode rendering retains its existing layout. Desktop controls are 26px; narrow-screen controls retain 44px touch targets.

An 88-line imported quotation fixture at 1280x768 improved from 3 fully visible rows (98px ordinary / 157px cost rows) to at least 10 (47-49px). At 1920x1080 at least 17 complete rows fit. Browser verification also covers field expansion, all row searches, responsive scrolling, keyboard navigation, inline creation and sortable identities. No pricing, totals, save or Workflow assignment behavior changes.
